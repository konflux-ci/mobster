# Component-level CBOM update via the augment commands

Build-time CBOM generated by Konflux can be further augmented, to include
information that is only known during a Konflux release, after the
`push-snapshot` Task. This information comes from a "mapped snapshot spec"
file, created by the `apply-mapping` task in a Konflux release pipeline.
Examples include OCI image tags or the image's release repository.

You can perform the augmentation via the mobster command: `augment cbom`.

## Augment cbom
You can either augment a specific OCI image by providing the optional
`--reference` argument, or augment SBOMs for all images in the supplied
snapshot:
```bash
$ mobster augment --output cboms/ cbom \
    --reference quay.io/repo/image@sha256:<digest> \
    --snapshot snapshot.json

$ mobster augment --output cboms/ cbom \
    --snapshot snapshot.json
```

This command is very similar to Augmenting OCI images, but handles only CBOMs.
It is expected that only 1 CBOM is created in the build tasks per component
(it is created by scanning the source code rather than scanning the images
for each architecture).
